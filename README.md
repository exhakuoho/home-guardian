# Home Guardian 守家

為高齡家庭設計的語音式智慧家庭守護系統。客廳的「主神」是一台本地運算的 AI 主機（NVIDIA Jetson Orin Nano SUPER），分散在各房間的「式守」負責感測與回報。長輩開口說話就能操作；夜間起床照明、瓦斯警示、電器未關與家屬通知由系統主動處理，而且不使用攝影機。

國立高雄科技大學 創新創業發展處「學生創意發想產業化激勵」計畫（民國 115 年）・DesignJarvis

## 線上展示

- 產品展示頁：https://home.designjarvis.com/homeguardian/
- 後台控制台：https://home.designjarvis.com/homeguardian/console.html

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 產品展示頁：枯山水風格的居家庭園地圖、六個守護情境模擬、語音示範、五層架構、創新比較、研發進程與團隊 |
| `console.html` | 後台控制台原型：總覽、設備、事件、提醒、規則、生活紀錄、家屬與通知、系統 |
| `screenshots/` | 控制台八個分頁的整頁截圖（1440 寬、2 倍解析度） |

兩個頁面都是單一 HTML 檔，不需建置，直接用瀏覽器開啟或部署到任何靜態主機即可。

## 注意

控制台的設備數值、事件與統計皆由瀏覽器模擬產生；使用者做的設定只保存在該瀏覽器的 localStorage，不會同步到其他裝置。
